# The Aeneid — A Companion

An interactive, self-contained reading companion to Virgil's *Aeneid*: an
original commentary and reference weaving together the poem's characters,
books, themes, and connections.

The entire app is a single static `index.html` file — no build step, no
dependencies, no network requests. Open it in any modern browser and it runs.

## Live site

Published with GitHub Pages at:

**https://bip-river.github.io/aeneid/**

### Enabling GitHub Pages (one-time)

Pushing `index.html` alone does not turn Pages on. In the repository settings:

1. Go to **Settings → Pages**.
2. Under **Source**, choose **Deploy from a branch**.
3. Select the **`main`** branch and the **`/ (root)`** folder, then **Save**.

The `.nojekyll` file in the repo root tells Pages to serve the static files
directly without running a Jekyll build.
